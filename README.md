# **📌 Project: E-commerce Website – Online Shop**







## **🛒 E-commerce Website – Online Shop**







**---**

### **📖 Description**



#### An e-commerce website developed as a course project. The system allows users to browse products, manage a shopping cart, place orders, and complete payments via PayPal and VNPay. The project also includes SEO optimization, email marketing, and live chat integration.





---

### **🛠 Technologies**



* #### PHP
* #### MySQL
* #### HTML, CSS, JavaScript
* #### PayPal API, VNPay
* #### Google Map API
* #### GitHub, VS Code





---

### **⚙️ Features**



* #### User registration and login
* #### Role-based access control (Admin / Customer / Manager)
* #### Product management (CRUD)
* #### Shopping cart (add, update, remove items)
* #### Online payment integration:

#### &nbsp;	+ PayPal (international)

#### &nbsp;	+ VNPay (domestic)

* #### Order history for sellers
* #### SEO-friendly URLs and Facebook sharing
* #### Email marketing subscription and campaign
* #### Live chat integration (3rd party)
* #### Contact form stored in database





---

### **▶️ How to Run (Local)**



1. Clone this repository:
   	*git clone https://github.com/your-username/ecommerce-website.git*
   ---
2. #### Move project to XAMPP *htdocs* folder.
3. Create database in MySQL and import SQL file:
   	*vutrudongho.sql*
   ---
4. #### Update database configuration in *config.php*.
5. #### Start Apache \& MySQL in XAMPP.
6. #### Access the website via browser:

#### &nbsp;	*http://localhost/VUTRUDONGHO/vutrudongho*
